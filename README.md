# Printable Bike Parts

A repo for bike parts you can 3d print

## Shimano 333 3-speed parts

Replacement parts for shimano 333 3 speed internal hub parts.

- [Top Cover](./shimano_333/TopCover.md) - Replaces often broken top cover.

## Clips

Various clips, tabs and screws used on bicycles.

- [Spoke Reflector Tab](./Clips/ReflectorSpokeTab.md) - Replaces tab used to hold reflectors on wheels via the spokes.
- [Spoke Reflector Screw](./Clips/ReflectorSpokeScrew.md) - Replaces screw used to hold reflectors on wheels via a spoke.
